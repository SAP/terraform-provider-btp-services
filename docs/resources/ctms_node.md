# btpservice_ctms_node (Resource)

Manages a CTMS node. Requires Terraform 1.14+. Import using its decimal ID or an identity containing endpoint and id. Omitted optional settings remain managed by CTMS.

## Example Usage

```terraform
resource "btpservice_ctms_node" "source" {
  name           = "DEVELOPMENT"
  description    = "Source node for the delivery pipeline"
  upload_allowed = true
  forward_mode   = "MANUAL"

  lifecycle {
    create_before_destroy = true
  }
}

resource "btpservice_ctms_node" "target" {
  name        = "QUALITY"
  auto_import = false

  targets = [{
    content_type     = "MTA"
    destination_name = "QUALITY_CF"
    import_options = {
      strategy = "default"
    }
  }]
}
```

## Schema

### Required

- `name` (String) Case-sensitive node name. Changing it replaces the node.

### Optional

- `auto_import` (Boolean) Automatically import eligible requests. Enabling this can immediately import queued requests and deactivate existing schedules.
- `description` (String) Node description, up to 512 characters. Supports Latin letters, numbers, spaces, and -._~:\/?#[]@!$&()*+,;=%. An empty string clears the description using API null. Omit to leave it managed by CTMS.
- `forward_mode` (String) Forwarding mode: AUTO (pre-import), POST_IMPORT, ON_SUCCESS, or MANUAL.
- `notification_enabled` (Boolean) Enable notifications. Requires an Alert Notification subscription and configuration in the subaccount.
- `targets` (Attributes List) Deployment targets in API order. Omit to leave targets managed by CTMS; an explicit empty list requests clearing them. Virtual nodes cannot have targets. (see [below for nested schema](#nestedatt--targets))
- `upload_allowed` (Boolean) Allow file uploads to this node.
- `virtual` (Boolean) Virtual nodes cannot have deployment targets.

### Read-Only

- `controlled_by` (String) Application controlling the node. Read-only until the API reset contract is confirmed.
- `id` (String) Decimal node ID assigned by CTMS.
- `job_id` (Number) Import scheduler job ID, if present.

## Import

Import is supported using the following syntax:

```terraform
# Use the provider configuration for the original CTMS landscape.
terraform import btpservice_ctms_node.source "12345"
```

## Restriction

### Labels of Nodes

The current version of the V2 API for cTMS landscape management (status: 23.11.2026) does not support the creation or modification of labels. Consequently the resource does not comprise these attributes.

### Import Settings of Nodes

The current version of the V2 API for cTMS landscape management (status: 23.11.2026) does not support the creation or modification of import settings. Consequently the resource does not comprise these attributes.
